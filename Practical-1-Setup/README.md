# Practical 1: Android Studio Setup and Hello World

## Objective
To install Android Studio, create a virtual device, and run a basic Hello World application.

## Description
In this practical, Android Studio was installed and configured. A virtual device (emulator) was created to simulate an Android device. A simple Hello World application was developed and executed on both emulator and physical device. The project structure, manifest file, and log statements were also explored.

## Components Used
- Android Studio  
- Emulator (Virtual Device)  
- Logcat  

## Steps Performed
1. Installed Android Studio.
2. Created a new Android project.
3. Set up a virtual device (AVD).
4. Ran the Hello World application.
5. Explored project structure and files.
6. Viewed log messages using Logcat.
